Ticket #024 — Model a Complete Kaggriculture Turn

Goal:
Change Dimitri's decision representation from a single action into a complete Kaggriculture turn.

Current limitation:
Decision currently wraps one Action. Kaggriculture turns can contain:
- one farmer action
- one action per hand
- multiple market orders

The Operator already has some support for composing these channels, but the upstream Planner/Executive representation only models one action.

   - planner/action.py

   - planner/simulator.py
   - planner/evaluator.py
   - executive/decision.py
   - executive/executive.py
   - operator/operator.py
   - pipeline.py
   - relevant tests

2. Introduce a small immutable representation for a complete turn.

It should explicitly represent:
   - farmer action
   - hand actions
   - market orders

Use the existing Action representation where appropriate rather than creating duplicate action types.

3. Update Decision so that it represents a complete turn rather than exactly one Action.

4. Update the Planner/PlanningResult interfaces as necessary so candidate plans can represent complete turns.

5. Update Executive so that it selects one complete turn candidate.
